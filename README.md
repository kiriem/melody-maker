# メロディーメーカー

5音スケールとピアノロールで旋律をつくり、MP3 として書き出せるブラウザ教材です。
中学校音楽科のワークショップ用に開発したものを、授業以外でも使えるかたちに整理したリリース版です。

## できること

- **音階（スケール）を選ぶ** — 5〜7音のスケールを 4 種類用意。選んだスケールに含まれない音は鍵盤・グリッドともにグレーになり、押しても鳴りません
- **鍵盤で音を確かめる** — クリック、またはキーボード（白鍵 `A S D F G H J K` / 黒鍵 `W E T Y U`）で演奏
- **ピアノロールで旋律をつくる** — 8小節（4/4拍子・BPM 120）、1マス = 16分音符。クリックで配置／削除、ノート右端のドラッグで長さを調整
- **再生・リピート再生**
- **元に戻す** — `Ctrl+Z` / `Cmd+Z`（50 手まで）
- **ランダム生成** — 2小節フレーズ単位で、順次進行を優先した旋律を自動生成
- **プリセット読み込み** — `presets.js` がある場合のみ表示（下記参照）
- **保存** — 自動保存 + 保存スロット A / B / C（いずれもブラウザの localStorage）
- **MP3 書き出し** — ブラウザ内でレンダリングしてダウンロード

## 動かし方

サーバも、ビルドも、API キーも不要です。`index.html` を開くだけで動きます。

```
open index.html
```

ローカルサーバ経由で開いてもかまいません。

```
python3 -m http.server 8000
# → http://localhost:8000
```

公開する場合は 2 ファイル（`index.html`, `presets.js`）を静的ホスティング（GitHub Pages、Netlify など）に置くだけです。

### 必要な環境

- モダンブラウザ（Chrome / Edge / Safari / Firefox の最新版）
- インターネット接続 — React・Tone.js・Tailwind・lamejs を CDN から読み込むため。完全オフラインで使うには各ライブラリをローカルに配置して `index.html` の `<script src>` を書き換えてください
- 音を鳴らすには最初に画面をクリック／タップする必要があります（ブラウザの自動再生制限）

## ファイル構成

```
index.html   アプリ本体（単一ファイル。React + Tone.js + lamejs を CDN から読み込む）
presets.js   プリセット旋律データ（任意）
```

## プリセット旋律について

`presets.js` は既存楽曲の冒頭旋律を採譜したデータを含みます。
授業内利用を前提に用意したものなので、**公開・再配布する場合は権利関係を確認してください。**

不要なら `presets.js` を削除するだけでよく、その場合はアプリ側で「プリセット」ボタンが表示されなくなるだけで他の機能に影響はありません。
`index.html` の `<script src="./presets.js">` 行も併せて削除しておくと 404 が出ません。

## スケールを追加・変更する

`index.html` の `melodyScales` を編集します。

```js
const melodyScales = {
    'scale1': {
        name: 'レ ファ ソ ラ シ♭ ド（レ）',   // UI に出す表示名
        example: '千本桜（黒うさP）',          // 「例：」として添える曲名
        notes: ['D', 'F', 'G', 'A', 'A#', 'C'], // 使える音（オクターブ抜きの音名）
        flatDisplay: { 'A#': 'シ♭' },          // ドレミ表記を♭で出したい音の対応表
    },
    // ...
};
```

`notes` に書いた音だけが鍵盤・グリッドで有効になります。
